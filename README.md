# 🍽️ AMI CHAISE — Лендинг ресторана

Адаптивный лендинг для ресторана **AMI CHAISE** в Москве, специализирующегося на завтраках, бранчах и бизнес-завтраках. Сайт включает информацию о двух филиалах, интерактивное меню, акции, коллаборации и функционал бронирования стола.

🔗 **Демо-версия**: [https://tiafk.github.io/AMI/](https://tiafk.github.io/AMI/)

## ✨ Особенности проекта

- **Полностью адаптивная и кроссбраузерная верстка**: корректное и пиксель-перфект отображение на десктопных и мобильных устройствах.
- **Модульная структура стилей**: использование SCSS/SASS с разделением кода на логические блоки и файлы для упрощения поиска, поддержки и масштабирования проекта.
- **Интерактивные элементы и анимации**: 
  - Слайдеры (карусели) с использованием библиотеки **Swiper.js** (блоки "День рождения" и "Коллаборации").
  - Бегущая строка (marquee-эффект).
  - Всплывающие окна (попапы) для выбора филиала и просмотра деталей коллабораций.
  - Анимированное бургер-меню с оверлеем для мобильной навигации.
- **Интеграция с Яндекс.Картами**: интерактивная карта с кастомными метками двух ресторанов и автоматическим масштабированием под границы объектов.
- **Оптимизация и чистота кода**: использование чистого CSS/JS, проверка на конфликты стилей через консоль разработчика, ленивая загрузка изображений (`loading="lazy"`), семантическая HTML5-разметка и SEO-метатеги (Open Graph, Yandex/Google verification).

## 🛠️ Используемые технологии

- **HTML5** (семантическая разметка, доступность)
- **SCSS / SASS** (препроцессор для организации и компиляции стилей)
- **CSS3** (Flexbox, Grid, анимации, медиа-запросы)
- **JavaScript (Vanilla JS)** (логика меню, попапов, инициализация слайдеров)
- **Swiper.js** (современная библиотека для создания тач-слайдеров)
- **Yandex Maps API** (интеграция интерактивной карты)
- **Yandex Metrika** (веб-аналитика)
